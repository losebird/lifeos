## Values
1. **腾出手**：我做的东西让人少做重复的事，把时间还给他们自己的要紧事。
2. **在场**：和我爱的人在一起时，我把注意力留在他们身上。
3. **普惠**：我做的系统，普通人用得上。
4. **要紧**：时间不够时，我先做真正要紧的那一件。
